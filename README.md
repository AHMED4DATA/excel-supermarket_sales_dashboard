# Supermarket Sales Dashboard

## Overview
This repository contains a **supermarket sales dashboard**, built using **Excel ** to visualize key sales metrics. The dashboard provides insights into:
- **Total Sales** across product lines
- **Branch-wise Profits**
- **Payment Method Trends**
- **Customer Purchase Patterns**

## Features
- **Dynamic slicers** for filtering by branch, product line, and payment type.
- **Interactive visuals** representing sales, profits, and customer behavior.
- **Pivot tables** summarizing key business insights.

## File Information
- `supermarket_dashboard.xlsx`: The main Excel file containing processed sales data.

## Usage
1. Open the **Excel file** to analyze raw data.
2. Import the **PBIX file** into Power BI for interactive analysis.
3. Adjust slicers and filters to explore sales trends.
